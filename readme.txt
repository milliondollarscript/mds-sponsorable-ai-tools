Launch sponsor-supported calculators, planners, quizzes, generators, and guides with lead capture and moderation.

== Description ==

Sponsorable AI Tools helps Million Dollar Script site owners publish small useful tools with sponsor placement, disclosures, lead capture, moderation, saved-result email delivery, and API-safe public tool data.

The browser output remains an informational preview. Saved-result email can be free, manually reviewed, or sent after both payment-provider checkout and administrator approval. Delivery is idempotent and failed mail can be retried by an administrator. Provider checkout goes through the Million Dollar Script core payments API and does not call WooCommerce or gateways directly.

== Installation ==

1. Upload and activate the extension.
2. Open Million Dollar Script -> Sponsorable AI Tools.
3. Create or edit a tool and place the shortcode on a page.
