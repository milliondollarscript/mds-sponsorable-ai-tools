# Changelog

All notable changes to Sponsorable AI Tools are documented here.

## 0.2.1 - 2026-10-21
- Tested with WordPress 7.1.3 and WooCommerce 11.2.1, and the plugin states the exact versions it was tested with, so WordPress and WooCommerce no longer report it as untested on a current site.
- Added opt-in uninstall cleanup through the core extension policy for extension-owned tools, leads, settings, and transients.

## 0.2.0 - 2026-07-15

- Open existing tools on the Leads queue while keeping new tool creation on Tool settings.
- Split tool configuration from searchable, paginated lead moderation and delivery with directly addressable Tool settings and Leads tabs.
- Schedule retention during `init` so first activation remains warning-free alongside plugins that add translated cron intervals.

## 0.1.0

- Added the initial Sponsorable AI Tools extension.
